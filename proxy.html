À quoi sert un proxy résidentiel ?

Un proxy fait transiter votre connexion par une autre adresse IP. Avec une IP résidentielle (celle d'un vrai particulier), vous apparaissez comme un internaute local ordinaire — les sites, boîtes mail et services ne bloquent pas votre trafic comme ils le feraient avec une IP de serveur.

Rester indétectable

Les IP résidentielles sont vues comme des connexions humaines normales. Idéal quand une IP de datacenter serait immédiatement signalée ou bloquée.

Apparaître dans le bon pays

Choisissez le pays (et l'opérateur) de sortie : votre trafic semble provenir d'un utilisateur local, où que vous soyez réellement.

Protéger vos envois

Combiné à EvoSender, le proxy masque votre IP réelle et répartit l'envoi, pour préserver votre réputation et votre délivrabilité.

Fiabilité & rotation

Un immense pool d'adresses : renouvelez l'IP à chaque requête, ou gardez la même le temps d'une session.

Rotative ou fixe (sticky)

🔄 IP rotative

Laissez le champ session vide : vous obtenez une nouvelle IP à chaque requête. Parfait pour l'extraction et les tâches à fort volume où l'on veut varier les adresses.

📌 IP fixe (sticky)

Renseignez un identifiant de session : vous gardez la même IP le temps de la session. Idéal quand un service exige une IP stable (connexion, envoi continu).

Questions fréquentes

Quelle différence avec un proxy datacenter ?

Une IP datacenter appartient à un hébergeur et est facilement identifiée et bloquée. Une IP résidentielle appartient à un vrai particulier via son fournisseur d'accès : elle passe pour un internaute normal, donc bien plus fiable.

Comment fonctionne le ciblage par pays ?

Vous choisissez le pays (et l'opérateur) dans le générateur de votre espace client ; les paramètres sont intégrés à vos identifiants. L'IP de sortie provient alors de la zone demandée.

Rotative ou sticky : que choisir ?

Rotative (session vide) = nouvelle IP à chaque requête, utile pour l'extraction. Sticky (session renseignée) = même IP le temps de la session, utile quand un service exige une IP stable.

Le forfait expire-t-il ?

Chaque forfait est valable 180 jours à partir de l'activation. Vous consommez votre volume de Go pendant cette période.

Puis-je l'utiliser avec EvoSender et EvoExtractor ?

Oui. EvoSender propose un mode d'envoi via proxy (et un mode hybride), et EvoExtractor peut extraire à travers le proxy pour éviter les blocages.

Mon IP réelle est-elle exposée ?

Non : votre trafic sort par l'IP résidentielle du proxy. Votre adresse réelle reste masquée.
